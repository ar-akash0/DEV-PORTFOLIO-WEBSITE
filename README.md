# Knox Telemetry & Systems Operations Portal

A centralized infrastructure telemetry portal, custom SA-MP socket query dashboard, and interactive retro arcade engine engineered by **Md. Abdullah Rahman (knox-akash)**.

## 🚀 Key Modules
- **Telemetry & Socket Monitor (`bsrp.php`, `samp.php`):** High-speed binary UDP query interface for SA-MP / open.mp servers with MySQL dynamic schema synchronization.
- **Master Operations Console (`admin.php`):** Lightweight administration interface to manage real-time broadcasts, project roadmaps, and dev logs.
- **Cyber Arcade Hub (`arcade.html`):** Canvas-based 2D/3D games featuring OutRun-style infinite racer and packet firewall matrix.
- **Forensic Shell (`cipher.html`):** Interactive cryptography simulation terminal.

## 🛠️ Stack
- **Backend:** PHP 8.x, MySQL, Native UDP Raw Sockets
- **Frontend:** HTML5, CSS3 Grid/Flexbox, Pure JavaScript (Canvas 2D Engine)
- **Infrastructure:** Linux VPS Daemon, systemd watchdog, Anycast CDN
